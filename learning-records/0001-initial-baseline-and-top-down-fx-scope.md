# 初期ベースラインと為替系（FX）トップダウン学習スコープの確定

学習者は既存の金融取引・契約データとCDMのデータ構造をマッピング・設計・レビューできるようになることを目的としており、金融ドメイン知識およびCDM（`.rosetta`）の双方を基礎からトップダウンアプローチ（`WorkflowStep` → `BusinessEvent` → `TradeState` → `Trade` → `Product` の全体鳥瞰から各論へ降りる順序）で学習する。対象とするOTCデリバティブは為替系（FX Spot/Forward/Swap、NDF/NDS、FXオプション［バニラ・NDO・アベレージレート・アベレージストライク・バリア・ギャップ］、およびCall＋Put合成×複数期日のシンセティック・マルチフォワード）と担保・法的契約（ISDA/CSA）に特化し、他の商品カテゴリはスコープ外とする。

## Implications
- 教材内のすべての例題・JSONサンプル・マッピング演習は、金利スワップ等ではなく為替取引（まずは最もシンプルな FX Forward の一次ソース実データ `execution-fx-forward-func-output.json` / `fx-ex03-fx-fwd.json`）を題材として統一する。
- 金融専門用語と `.rosetta` 構文の双方が初出となるため、認知負荷（Working Memory消費）を抑えるべく、1レッスンにつき1つの明確な構造階層に絞り、リファレンス（用語集・構文チートシート）を常時参照可能にする。
